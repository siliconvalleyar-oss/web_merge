# WebMerge Studio — Documentación

Landing page profesional con animaciones GSAP, diseño glassmorphism y arquitectura SPA.

## Stack

| Capa | Tecnología |
|------|------------|
| Backend | Node.js + Express 4.x |
| Frontend | HTML5 + CSS3 + Vanilla JS |
| Animaciones | GSAP 3.12 + ScrollTrigger + AOS 2.3 |
| Fuentes | Inter + JetBrains Mono (Google Fonts) |
